# QingYu-Sou（清羽盘搜）

清羽盘搜是基于 [PanSou](https://github.com/fish2018/pansou) 的二开版本：Vue 3 前端 + Go 后端同仓构建成一个镜像，在保留上游搜索 API 的基础上，补齐了**账户体系、每日配额、OAuth2 登录和完整的管理后台**。

- 项目地址：[LiuShen-Fork/pansou-web](https://github.com/LiuShen-Fork/pansou-web)
- 本应用使用的镜像：`ghcr.io/liushen-fork/pansou-web:v1.3.1`（amd64 / arm64）
- 上游：清羽盘搜的后端以 subtree 方式跟随 [fish2018/pansou](https://github.com/fish2018/pansou)

> 本仓库另有 `pansou` 应用，那是上游官方的前后端一体镜像；清羽盘搜是它的二开版本，多了账号与后台，两者不要混装在同一端口上。

## 使用说明

- **HTTP 端口**：容器内 nginx 监听 `80`，安装表单里的端口是宿主机端口（默认 `45964`）。页面与 API 都走这一个端口。
- **访问域名**：只用于容器内 nginx 的 `server_name`。容器里只有一个站点，填错也不影响访问；走 1Panel 反向代理时这一项可有可无，保留它是为了使用镜像内置 HTTPS 时能与证书域名对上。
- **数据持久化**：全部在 `./data`（容器内 `/app/data`），包括账户数据库 `pansou-admin.db`、搜索缓存、前后端日志和 SSL 证书。**备份应用目录等于备份账号与配置**，升级镜像不会丢。
- **首次启动**：容器会初始化账户数据库，首次启动到页面可访问需要十几秒。

## 初始管理员

首次启动自动创建：

| 账号 | 密码 |
| --- | --- |
| `admin` | `admin123456` |

登录后会**强制要求修改密码**，修改前只能访问用户中心与修改密码接口。公网部署前请先改密码。

## 安装表单字段

只有两个字段，其余运行参数都在管理后台里配置：

- **HTTP 端口**（`PANEL_APP_PORT_HTTP`）：宿主机端口，默认 `45964`。
- **访问域名**（`DOMAIN`）：见上面的说明，默认 `localhost`。

## 管理后台

登录后进入「管理后台」，主要分三块：

- **认证与站点**：用户注册（邮箱验证码）、OAuth2（GitHub / Google / Linux DO / 通用 OIDC）、每日搜索配额、匿名搜索防护、个人 API 令牌开关、站点名称与图标、公告（支持 Markdown）。OAuth2 回调地址统一填 `https://你的域名/api/auth/oauth/callback`。
- **运行参数**：代理地址、缓存开关与 TTL、默认并发、出口并发、网页搜索签名密钥。**后台里的值优先于环境变量**，其中 TTL、并发和签名密钥改完即时生效，代理、缓存开关与出口并发需要重启容器。
- **上游自动同步**：TG 频道与启用插件列表。镜像构建与运行时会自动抓取上游的默认值，一般不用手工维护；需要自定义时在后台覆盖。

管理员账号在数据库层是唯一的，接口不能新增、提升或删除管理员。

## API 使用

`/api/search` 的参数与响应结构与上游 PanSou 完全一致，可直接接入视频源、机器人等应用。与上游的差别只有访问控制：**默认要求登录**，未携带有效凭证返回 `401`，超出每日额度返回 `429`。

```bash
# 用户中心 → API 令牌 里创建，形如 ps_xxxx（明文只显示一次）
curl -H "Authorization: Bearer ps_xxxxxxxx" \
     "http://你的地址:45964/api/search?kw=仙逆"
```

令牌也可以放在 `X-API-Token` 头里；同一账号的所有令牌共享每日额度，管理员还能为单个用户单独设置仅 API 的额度。网页端的匿名搜索走 `/api/web/search`，需要页面签发的短期凭证，**不是公开 API**。

## 忘记管理员密码

用一次性环境变量重置：在「已安装应用 → 参数 → 编辑 → 高级设置 → 编辑 docker-compose.yml」里给服务加一行 `PANSOU_RESET_ADMIN: "1"`，重启容器后它会把第一个管理员重置为默认密码并强制改密，**随后务必删掉这一行**。

另一种办法是删除 `./data/pansou-admin.db` 重新初始化——这会清空全部账户数据。

## 反向代理与 HTTPS

- **推荐用 1Panel 反向代理**：网站 → 创建网站 → 反向代理 → 目标填 `http://127.0.0.1:<宿主机端口>`，证书在 1Panel 里申请和续期，不需要改 Compose。
- **镜像内置 HTTPS**：把证书放到 `./data/ssl/fullchain.pem` 与 `./data/ssl/privkey.pem`，容器检测到后会自动把 80 跳转到 443 并启用 TLS。注意本应用的 Compose 默认只映射了 80，使用内置 HTTPS 时需要自己加一条 `443` 端口映射，并在上面把「访问域名」填成证书对应的域名。
- 两种方式不要同时用，否则会绕一层代理。

## 升级与备份

- 升级只替换镜像，`./data` 里的账户、缓存与证书保持不变。
- 备份：直接备份 `./data`（重点是 `pansou-admin.db`）。
- 版本跟随上游的 `v` 标签；镜像同时提供 `latest`，但本应用固定使用明确版本号，升级由应用商店的版本目录控制。
